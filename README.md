# LearnMate AI – AI-Powered Learning Platform

## About the Project

LearnMate AI is an interactive learning platform designed to help students organize their courses, study materials, quizzes, exams, and revision activities.

## Live Website

**[Click here to use LearnMate AI](https://learnmate-ai-di1r.hatchable.site/)**

## Features

- Dashboard to view learning activities
- Course management
- Study material management
- AI Tutor for learning support
- AI-powered practice quizzes
- Mock exam practice
- Topic exploration
- Learning progress tracking
- Revision Center
- Study Planner

## Technologies Used

- HTML
- CSS
- JavaScript
- Groq API for AI features
- Hatchable for hosting and backend services
- PostgreSQL database provided by the platform

## How to Use

1. Open the live website using the link above.
2. Sign in to your account.
3. Create a course and add your study notes.
4. Use the AI Tutor and Practice Quiz features.
5. Review your learning progress.

## Project Goal

The goal of LearnMate AI is to make learning more organized, interactive, and accessible for students.
